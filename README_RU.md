# Project Based Learning (Русская версия)

Список учебных пособий по программированию, в которых начинающие разработчики учатся создавать приложение с нуля. Эти учебники разделены по основным языкам программирования. Учебные проекты могут использовать несколько технологий и языков.

Чтобы начать, просто форкните этот репозиторий. Пожалуйста, обратитесь к [CONTRIBUTING.md](CONTRIBUTING.md) для правил участия.
